# Code of Conduct

## Our Pledge

We pledge to make participation in this project welcoming, respectful, and harassment-free for everyone.

## Expected Behavior

- Be kind and constructive.
- Assume good intent while being clear about impact.
- Focus criticism on ideas and code, not people.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private information without permission.
- Repeated disruption of project spaces.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors that violate this code of conduct.
