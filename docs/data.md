# Data Contract

Catalog URL: https://baditaflorin.github.io/group-theory-visualizer/data/v1/groups.json

Metadata URL: https://baditaflorin.github.io/group-theory-visualizer/data/v1/groups.meta.json

Schema version: `group-catalog/v1`

## Artifact Shape

```json
{
  "schemaVersion": "group-catalog/v1",
  "generatedAt": "1970-01-01T00:00:00.000Z",
  "source": "deterministic local catalog",
  "groups": []
}
```

Each group contains:

- `id`
- `name`
- `shortName`
- `family`
- `order`
- `description`
- `presentation`
- `symmetryKind`
- `elements`
- `operationTable`
- `generators`

## Generation

The catalog is generated by:

```sh
node scripts/write-static-data.mjs
```

`make build` runs this automatically before Vite builds the Pages site.

The output is deterministic except for `groups.meta.json`, which records when the local artifact was
written.

## Versioning

Breaking schema changes must move to `/data/v2/`. V1 consumers can depend on `/data/v1/groups.json`
remaining table-backed and order-indexed.
