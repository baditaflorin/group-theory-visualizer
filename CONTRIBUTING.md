# Contributing

Thanks for helping improve Group Theory Visualizer.

## Local Setup

```sh
npm install
make install-hooks
make test
make smoke
```

## Commits

Use Conventional Commits:

- `feat: add group explorer`
- `fix: correct cayley edge generation`
- `docs: explain deployment`
- `test: cover dihedral products`

## Pull Requests

Keep changes focused, include tests for behavior changes, and run `make lint`, `make test`, and `make smoke` before publishing.
